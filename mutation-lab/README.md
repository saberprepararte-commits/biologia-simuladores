# Mutation Lab

Simulador educativo de mutaciones genéticas en un solo archivo HTML.

## Cómo usarlo

Abre `index.html` en el navegador.

## Publicar en GitHub Pages

1. Sube esta carpeta a un repositorio de GitHub.
2. En el repositorio, entra a `Settings > Pages`.
3. En `Build and deployment`, elige `Deploy from a branch`.
4. Selecciona la rama principal y la carpeta raíz.
5. Guarda los cambios.

La aplicación no necesita instalación, servidor ni dependencias externas.

## Contenido

- `index.html`: aplicación completa con HTML, CSS y JavaScript integrados.

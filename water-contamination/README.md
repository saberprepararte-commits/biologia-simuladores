# AquaLab

Simulador educativo de calidad del agua y contaminacion ambiental.

## Publicar en GitHub Pages

1. Sube el contenido de esta carpeta a un repositorio de GitHub.
2. En GitHub, abre `Settings > Pages`.
3. En `Build and deployment`, selecciona `Deploy from a branch`.
4. Elige la rama `main` y la carpeta `/root`.
5. Guarda los cambios y espera a que GitHub genere la pagina.

El simulador funciona directamente desde `index.html`.

## Probar localmente

```bash
npm install
npm run dev
```

Luego abre la direccion que indique Vite, normalmente:

```text
http://127.0.0.1:5173/
```

## Compilar

```bash
npm run build
```
